The `@streamdown/code` plugin provides syntax highlighting for code blocks using [Shiki](https://shiki.style/).

- Supports 200+ programming languages
- Languages are lazy-loaded on demand
- Dual theme support (light/dark mode)
- Token caching for performance

## Install

```package-install
npm install @streamdown/code
```

## Usage

```tsx
import { code } from '@streamdown/code';

<Streamdown plugins={{ code }}>
  {markdown}
</Streamdown>
```

## Custom configuration

```tsx
import { createCodePlugin } from '@streamdown/code';

const code = createCodePlugin({
  themes: ['github-light', 'github-dark'], // [light, dark]
});
```

## Worker-backed highlighter pattern

If your app needs stricter main-thread isolation, implement a custom `CodeHighlighterPlugin` that forwards highlight work to a Web Worker.

```tsx
import type { CodeHighlighterPlugin, HighlightOptions, HighlightResult } from '@streamdown/code';

export function createWorkerCodePlugin(): CodeHighlighterPlugin {
  const worker = new Worker(new URL('./code-worker.ts', import.meta.url), {
    type: 'module',
  });

  const cache = new Map<string, HighlightResult>();
  const subscribers = new Map<string, Set<(result: HighlightResult) => void>>();

  worker.onmessage = (event) => {
    const { key, result } = event.data as { key: string; result: HighlightResult };
    cache.set(key, result);
    const listeners = subscribers.get(key);
    if (!listeners) return;
    for (const listener of listeners) listener(result);
    subscribers.delete(key);
  };

  return {
    name: 'shiki',
    type: 'code-highlighter',
    supportsLanguage: () => true,
    getSupportedLanguages: () => [],
    getThemes: () => ['github-light', 'github-dark'],
    highlight(options: HighlightOptions, callback) {
      const key = `${options.language}:${options.themes.join(':')}:${options.code}`;
      const cached = cache.get(key);
      if (cached) {
        return cached;
      }

      if (callback) {
        const set = subscribers.get(key) ?? new Set();
        set.add(callback);
        subscribers.set(key, set);
      }

      worker.postMessage({ type: 'highlight', key, options });
      return null;
    },
  };
}
```

Use this pattern to preserve Streamdown's sync-cache/async-callback contract while moving heavy tokenization out of the UI thread.
